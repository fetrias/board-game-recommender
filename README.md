# Сервис рекомендаций настольных игр

## Назначение

Сервис предназначен для помощи пользователям в выборе настольных игр с учетом характеристик игр, количества участников и пользовательских оценок.

## Целевая аудитория

Люди, которые хотят выбрать подходящую настольную игру для семьи, друзей или игровой компании.

## Предметная область

Сервис хранит сведения о пользователях и настольных играх, распределяет игры по категориям и формирует персональные рекомендации на основании предпочтений и параметров игровой компании.

## Основные сущности

- Пользователь: имя, возраст и предпочтения.
- Игра: название, категории, допустимое количество игроков и оценки.
- Категория: тематическая или жанровая принадлежность игры.
- Рекомендация: результат проверки соответствия игры запросу пользователя.

## Возможности

- просмотр каталога и подробной информации об играх;
- поиск игры по части названия;
- подбор игр по количеству участников и категории;
- сортировка игр по средней оценке;
- добавление и отмена последней оценки;
- вывод количества оценок и среднего значения;
- сохранение изменений в JSON-файле;
- обработка некорректного пользовательского ввода.

## Структура проекта

- `main.py` — меню и точка запуска приложения;
- `games.py` — информация об играх, поиск, сортировка и оценки;
- `recommendations.py` — фильтрация и формирование рекомендаций;
- `storage.py` — загрузка и сохранение данных в JSON;
- `utils.py` — безопасный пользовательский ввод;
- `data/games.json` — каталог игр и оценки;
- `tests/` — автоматизированные тесты;
- `requirements.txt` — инструменты тестирования и проверки кода.

## Формат данных

Каждая игра в `data/games.json` содержит идентификатор, название, категории,
минимальное и максимальное количество игроков, а также список оценок.

## Требования

- Python 3.10 или выше;
- pytest;
- flake8.

Установка зависимостей:

```bash
python -m pip install -r requirements.txt
```

## Запуск программы

```bash
python main.py
```

## Запуск тестов

```bash
python -m pytest
```

## Проверка качества кода

```bash
python -m flake8
```
