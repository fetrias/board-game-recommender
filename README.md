# Сервис рекомендаций настольных игр

## Назначение

Сервис предназначен для помощи пользователям в выборе настольных игр с учетом характеристик игр, количества участников и пользовательских оценок.

## Целевая аудитория

Люди, которые хотят выбрать подходящую настольную игру для семьи, друзей или игровой компании.

## Предметная область

Сервис хранит сведения о пользователях и настольных играх, распределяет игры по категориям и формирует персональные рекомендации на основании предпочтений и параметров игровой компании.

## Основные сущности

- Пользователь: имя, возраст и предпочтения.
- Игра: название, возрастное ограничение и допустимое количество игроков.
- Категория: тематическая или жанровая принадлежность игры.
- Рекомендация: результат проверки соответствия игры запросу пользователя.

## Основные функции

- Получение краткой информации о настольной игре.
- Проверка соответствия игры указанному количеству участников.
- Расчет средней оценки игры на основе пользовательских оценок.

## План развития

На следующих этапах планируется:

- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
